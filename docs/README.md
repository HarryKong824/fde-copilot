## ⚠️ 读文档前请知道三件事

### 1. 计数都写了「口径」

本项目所有涉及**数量**的断言，都注明了**这个数字数的是什么集合**。

**为什么**：同一个项目里，「根目录文件数」（354）和「递归 md 数」（198）**不是同一个集合**，
相减会得到没有意义的数。**如果你看到某个数字没有口径，那是一个缺陷，请报出来。**

---

### 2. 有些结论标了「仅离线」/「部分活验」

这**不是**「没做」，而是「**做了，但没能在真环境里验完**」。

| 档位 | 含义 |
|---|---|
| 活验完整 | 在真实 DSH 进程里跑通并留下证据 |
| **部分活验** | 接线已活验，**核心判据仅离线** |
| **部分未验** | 明确列出的缺口 |

19 项中：**15 项活验完整 / 2 项部分活验 / 2 项部分未验 / 0 项未实现**。

---

### 3. 文档互有交叉引用，且**引用带版本**

本项目在无 git 时期开发，**行号会随修订漂移**。
凡是引用行号的地方，都应注明**「相对哪一版」**——这是本项目踩过坑后立的规矩。

> 📌 如果你发现某处引用的行号**对不上**，先确认它标的是哪一版，**不要急着报缺陷**。
