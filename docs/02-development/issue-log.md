## 一、先说清一件事：这份台账为什么这么长

**因为「记录错误」是这个项目的机制，不是它的污点。**

本项目的每一批交付都有一道**核证环节**：核证方不看实现方的说明，**直接去磁盘上重新算一遍**（重新 parse 审计链、重算哈希、重跑测试、逐名 diff 工具面）。差异一律记入 `_inbox/`。

所以这份 47 条里，**绝大多数在交付前就被抓住并改正了**。

| 如果 | 说明 |
|---|---|
| 一个错误**被记录**且**被改正** | ✅ **机制生效**——这正是这套系统存在的意义 |
| 一个错误**没被记录** | ❌ 这才是真正的风险，而它**不在这份台账里**（因为没人知道） |

### 三条最值得记住的

#### 🔴 #9 `tools/_replay_phase_audit.mjs`——**报警器自己不会报警** ✅ **已修复（2026-09-29）**

> **现状**：`JSON.parse` 已被 try/catch 包住（`:45-47` 逐行解析、`:86` / `:99` 两处 `.map` 均 `catch → null` 兜底），
> `:135` 为 `process.exitCode = bad === 0 ? 0 : 1`。当场跑过：`断链 0 处 / RESULT: CHAIN-INTACT / EXIT=0`。
> **下面保留的是当时的事故形状**——因为它记的是"教训"，不是"当前状态"。

```
lib 里裸取：JSON.parse(line)          ← 链有一行坏，就 SyntaxError
后果：整个脚本崩掉 → 零输出
而它的用途恰恰是「链坏的时候跑它来确认哪里坏了」
```

> **教训**：**「崩溃」不是判据**——崩一次会让**整份报告消失**，看起来就像「什么也没发生」。
> **固定动作**：先断言「该条存在」，再断言真假；崩溃必须被捕获并**明确报告为「无法判定」**，而不是静默退出。

---

#### 🔴 #11 0 字节的测试文件——**空程序必然「全绿」**

```
node 跑一个空文件 → 零断言 → 退出码 0
产物文件里写着「PASS 9 / FAIL 0」
⇒ 结果文件【不能自证】测试跑过
```

> **固定动作（三件套）**：
> ① 查脚本**字节数**（`ls -la`；⚠️ **别用 `wc -l`**——无换行符的文件也报 0）
> ② **当场重跑**
> ③ 取**退出码**（⚠️ `cmd A && node X; echo $?` 的 `$?` 是 `cmd A` 的）

---

#### 🔴 #4 D2 判据只验格式不重算——**门禁看起来在工作**

```
判据②只检查 hash 字段【长得对不对】（格式）
从不拿内容【重新算一遍】
⇒ 改了内容，hash 格式还是对的 ⇒ 判「完整」
```

> **教训**：**「能观测到」≠「会被判红」**。
> 一个检查器必须对自己的**合成坏样本**判红，**不红就自己 exit 1**。

### 🔴 05 号（`0050`）的完整经过——**判据被证伪**

| | |
|---|---|
| **原先用的判据** | 「工具面**逐名 diff**」——看 header 里少了哪些工具 |
| **实测发现** | 16 条 header 里 `pwsh` 跳变 **10 次**，其中 **8 次无链记录伴随**，而 **10 次的 diff 形状逐字相同**（`移除["pwsh"]` / `新增["pwsh"]`） ⇒ **无区分力** |

> **这条的价值**：**「判据错了」比「实现错了」更难发现**，因为判据错了不会报错——
> 它只会给你**一个看起来很正常的答案**。

### 两条值得展开的

#### 🟡 `0059` **stale red**——「红灯已解除，但没人去把灯改绿」

```
问题已修复 ⇒ 红灯本该消失
但 README 里那条记录【没人改】
⇒ 后来的人读到它，会以为问题还在
```

> **教训**：**修复问题**和**更新记录**是**两个动作**。
> 只做前一个，文档就会**持续撒谎**——而且是往「更严重」的方向撒谎。

---

#### 🟡 `0062` **README 源↔副本漂移**

```
项目有「源目录 ↔ 部署副本」两套文件
tests/_deploy_diff.mjs 负责对拍
本项目真实踩过：只改了源 README 忘了同步副本
⇒ 报 HAS-DIFF，而 14 个文件里【只有这一处】不一致
⇒ 极易被误读成「代码没同步」
```

> **关键认知**：**对拍的「域」包含 `README.md`**，不只是 `lib/*.js`。
> README **不参与运行时** ⇒ 补一次 `cp` 即可，**不必重启**。
